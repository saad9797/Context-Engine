# Draft for the owner to publish after the launch gates pass

I'm opening an early beta of Contexa and looking for 5–10 developers to try it.

Contexa turns a project snapshot into an AI handoff for a specific coding task.
It also helps you explore how the application's sources connect, with a system
overview and a searchable database ERD.

Try it: https://contexa.tech

For your first run, start with a small public/sample project, describe one change,
and prepare a handoff. Use it in your AI tool, then review the changes and run
your project's checks.

This is an early beta: the server may need about a minute to wake up, and I want
honest feedback on confusing steps, slow preparation, and missing context. The
AI output still needs your review; Contexa does not guarantee working code.

If you try it, tell me: where did you get stuck, and did the handoff save you
time? Please keep private source and credentials out of public comments.
